# TigerUp

## Context
A solo side project, currently in beta. TigerUp is uptime monitoring for small teams: public status pages, email alerts, and a one-step import from UptimeRobot.

## Problem
The brief is uptime monitoring for small teams, with public status pages and email alerts, plus a one-step import from UptimeRobot. I am building it on my own, and it is in beta.

## Approach
- **Status page:** a public status page where TigerUp monitors itself.
- **Import:** one-step import from UptimeRobot.
- **Checks:** SSRF-hardened URL checks.
- **Auth:** rate-limited auth.
- **Stack:** Next.js, .NET, and PostgreSQL.

## Outcome
In beta at [tigerup.dev](https://tigerup.dev/?utm_source=portfolio&utm_medium=referral). Built solo. The status page, the UptimeRobot import, the URL checks, and auth are the scope of what is shipped so far.
